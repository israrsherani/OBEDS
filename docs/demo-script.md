# OBEDS Demo Script

1. Student A logs in and lists "Data Structures Book".
2. Student B logs in, searches for the book and sees it in the list.
3. Student B clicks "Request this book".
4. Student A opens Incoming Requests and sees the Pending request.
5. Student A clicks Accept. Status changes to Accepted.
6. The book disappears from the available books list.

Reject path: Student A clicks Reject. The request becomes Rejected and the book stays available.
