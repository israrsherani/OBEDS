
# OBEDS
## Online Book Exchange and Donation System

OBEDS is a web-based platform that allows students to list, search, exchange, and donate books.

## Features
- User registration and login
- List books for exchange or donation
- Search and filter available books
- Send book requests
- Accept or reject incoming requests
- Track request status
- Admin dashboard and management

## Technologies Used
- HTML
- CSS
- PHP
- MySQL
- JavaScript
- XAMPP
- phpMyAdmin

## Project Setup
1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Place the OBEDS project folder inside htdocs.
4. Open phpMyAdmin.
5. Create or select the database named obeds-db.
6. Ensure the required tables are present.
7. Open the project in your browser:

   http://localhost/OBEDS/
